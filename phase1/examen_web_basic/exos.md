# Exercices – HTML / CSS / JS

## Partie 1 : HTML (10 exos)

1. Écris le squelette HTML minimal d’une page.
2. Crée un titre `<h1>` avec ton prénom.
3. Ajoute un paragraphe contenant 2 phrases.
4. Ajoute une image avec `src="photo.jpg"` et texte alternatif.
5. Crée une liste non ordonnée de 3 fruits.
6. Crée une liste ordonnée de 3 étapes pour faire un café.
7. Crée un lien vers `https://openai.com` avec le texte "OpenAI".
8. Ajoute un tableau avec 2 colonnes (Nom, Âge) et 2 lignes de données.
9. Encapsule un mot d’un paragraphe dans un `<span>` avec `class="highlight"`.
10. Crée une structure avec `<header>`, `<main>`, `<footer>`.

## Partie 2 : CSS (10 exos)

1. Écris une règle CSS pour mettre tout le texte en rouge.
2. Cible seulement les `<h1>` et mets-les en bleu.
3. Crée une classe `.important` qui met le texte en gras.
4. Crée un id `#special` qui met le texte en italique.
5. Ajoute un fond jaune à tous les paragraphes.
6. Ajoute une bordure noire de 2px autour d’une div.
7. Centre le texte d’un titre.
8. Change la taille de police d’un paragraphe en 20px.
9. Utilise Flexbox pour centrer horizontalement deux divs.
10. Fais que les liens changent de couleur au survol (`:hover`).

## Partie 3 : JavaScript (10 exos)

1. Déclare une variable `prenom` avec ton prénom.
2. Affiche `"Bonjour"` + ton prénom dans la console.
3. Écris une fonction `carre(x)` qui renvoie le carré de `x`.
4. Crée un tableau contenant 3 nombres.
5. Utilise une boucle `for` pour afficher les nombres du tableau.
6. Crée une condition : si `age >= 18` affiche `"Majeur"`, sinon `"Mineur"`.
7. Récupère un élément avec `id="titre"` et change son texte en `"Hello"`.
8. Crée un bouton qui affiche `"Clique!"` dans la console quand on clique.
9. Crée un champ texte et un bouton : au clic, affiche la valeur du champ.
10. Crée une fonction qui change la couleur du fond de la page en vert.
